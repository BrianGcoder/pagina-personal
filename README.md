# Página personal de Brian Gil

## ¿Qué es esta página?

Es una página sencilla para presentarme y mostrar algunos de mis proyectos.

## ¿Qué muestra?

- Una foto, mi nombre y una breve presentación.
- Mis habilidades, los lenguajes que estoy aprendiendo y mi enfoque en desarrollo web.
- Enlaces a mis proyectos: Inwit Agents, Rueda Libre y ejercicios de Algoritmia y IA.

## ¿Por qué la hice?

La hice para que otras personas puedan conocerme, saber qué estoy aprendiendo y visitar mis proyectos desde un solo lugar.

## Proyectos

- **Inwit Agents:** [ver el repositorio](https://github.com/BrianGcoder/inwitagents).
- **Rueda Libre:** [abrir el sitio](https://briangcoder.github.io/rueda-libre/) o [ver el repositorio](https://github.com/BrianGcoder/rueda-libre).
- **Algoritmia y IA:** [abrir la página de ejercicios](https://briangcoder.github.io/algoritmia-y-ia/javascript/ahorro-semanal/) o [ver el repositorio](https://github.com/BrianGcoder/algoritmia-y-ia).

## Cómo ver la página personal

Abre el archivo `index.html` en un navegador. No necesitas instalar programas ni dependencias.

## Archivos principales

- `index.html`: contenido de la página.
- `styles.css`: colores, diseño y adaptación a pantallas pequeñas.
- `imagen/foto-perfil.jpg`: foto de perfil.

La página está hecha con HTML y CSS; no utiliza JavaScript.
